# 🚀 PadhaiPoint

An AI-powered backend system that helps users transform study material into **summaries, flashcards, and quizzes** automatically. This project aims to act as a smart learning assistant using AI.

---

## 📌 Project Overview

This project allows users to upload documents (PDFs, text files, etc.) and automatically generate:

- 📄 Concise summaries  
- 🧠 Flashcards for revision  
- ❓ AI-generated quizzes  

It reduces manual effort and improves study efficiency by converting raw content into structured learning material.

## 🧠 Features

### 1. Document Processing
- Upload files (PDF, TXT)
- Extract and clean text

### 2. AI Summarization
- Generate short summaries
- Highlight key points

### 3. Flashcard Generation
- Convert content into Q&A format
- Useful for revision

### 4. Quiz Generation
- Generate MCQs / questions
- Helps in self-assessment
